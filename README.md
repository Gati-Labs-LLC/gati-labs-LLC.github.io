# gati-labs.com

The Gati Labs LLC website, served by GitHub Pages at https://gati-labs.com (the `CNAME` file sets the domain).

Plain HTML and one stylesheet: no build step, no cookies, no analytics, no outside fonts or scripts. Pages: `index.html`, `apps.html`, `about.html`, `privacy.html`. Copy comes from the reviewed Gati Labs website copy doc.

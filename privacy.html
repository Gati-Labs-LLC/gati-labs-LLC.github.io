This website

  • No cookies, no analytics, no tracking. We don’t use advertising or analytics tools, and we don’t build a profile of visitors. The site loads no outside fonts or scripts.
  • Hosting. The site is hosted by GitHub Pages. Like most web hosts, GitHub may keep basic server logs, such as your IP address, for security. See GitHub’s privacy statement.
  • Email. If you email us, we use your message and address only to reply. We don’t add you to a mailing list unless you ask.
